# MyAnyu.com - Dating Proposal Website 💕

A beautiful, interactive surprise proposal website for Ananya!

## 🎁 Features

- **Gift Claim Page**: Animated gift box with spinning effects
- **Proposal Page**: Reveal with Yash's name and interactive buttons
- **Funny No Button**: Evades clicks 5 times with funny messages
- **Date Location Selection**: 6 romantic location options
- **Celebration**: Hearts and confetti animation with selected location

## 🎬 User Flow

1. **Gift Page** → Claim the gift
2. **Proposal** → Yes/No buttons (No evades!)
3. **Location Selection** → Pick date spot
4. **Celebration** → Confetti and hearts!

## 🚀 Local Development

```bash
# Start local server
python3 -m http.server 8000

# Open in browser
http://localhost:8000
```

## 📦 Deployment to Netlify

1. Push to GitHub
2. Connect GitHub repo to Netlify
3. Deploy automatically!
